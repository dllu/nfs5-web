# Portable save backups

The Game menu and quit screen both download and upload a versioned JSON backup.
It contains the local game files, including profiles, in-game settings, replays
when present, and deletion records. Downloading during play checkpoints files
the game has already written. Quitting through the original menus serializes
the current career.

Restore validates the backup against the current executable, asks for
confirmation, replaces the IndexedDB overlay in one transaction, and restarts
the game. Existing databases upgrade in place. Checkpoints from game sessions
that loaded an earlier overlay are rejected after a restore. Web view distance,
skybox selection, and touch layout are per-browser preferences.

`npm test`, `npm run test:usability`, and `npm run test:public` passed. The
public test created a profile, downloaded it, rejected a malformed backup,
cancelled a restore, and replaced the overlay through the Game menu. It then
quit through the original game, verified a deletion record in the download,
and restored the original profile byte for byte from the quit screen.
Additional Chrome checks verified database migration, transaction rollback,
and stale checkpoint protection. The backup codec preserved binary data,
Windows-1252 filenames, directory metadata, and deletions in a round trip.
