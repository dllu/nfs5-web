# WebGPU rendering backend

Added a WebGPU backend for Thrash's transformed/lit vertices, using the existing
portable host's MIT projection, fog, layout and blend conventions. This backend
is not yet connected to the original game's 41-export driver interface. Original
startup still stops while loading `drivers\opengl3z`.

The backend retains 32-byte guest vertex layouts, decodes ARGB colors, uses
perspective UVs and screen-linear color/fog interpolation, and supports depth
tests/writes, blending, alpha tests, scissor clipping and fog. Texture mutation
flushes earlier draws before changing texels. Vertex/index/effect data upload in
batches; compatible consecutive draws coalesce into one indexed draw. Frame
presentation shares a command submission with the frame's rendering operations.

Validation on the NVIDIA GB10 in Chrome 157 passes 27 known-pixel and batching
checks: color layout, geometry bounds, depth, alpha blend/test, texture orientation,
clipping, fog, unequal-RHW perspective interpolation, alpha modulation, ordered
texture updates, draw coalescing, canvas presentation and 3840x2160 output.
One hundred compatible input draws produce one GPU draw. Validation reports no
GPU errors. A separate transferred OffscreenCanvas test renders known foreground
and background pixels in a dedicated Worker, matching the game's planned host
threading model. The screenshot and report are in ignored `build/` files.

Normal Chrome obtains a hardware NVIDIA adapter without additional GPU flags.
Headless Chrome's Vulkan path intermittently returns no adapter with a Dawn
instance-lifetime message, so `npm run test:renderer` uses the normal browser by
default. `NFS5_GPU_HEADLESS=1` enables the headless test flags for investigation.
No global browser or driver settings were changed.

The next implementation step is the native Thrash bridge and command transport,
then the window/message services reached by original driver initialization.
These synthetic checks establish backend behavior; they do not establish game
visual compatibility, playability, or the 4K/120 Hz target.
